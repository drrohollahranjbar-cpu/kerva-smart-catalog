# کاتالوگ هوشمند کروا (Kerva) — بسته آماده استقرار روی Railway

## امکانات
- کاتالوگ فارسی و راست‌چین محصولات
- پیش‌فاکتور با امکان تغییر تعداد؛ قیمت و تخفیف از پایگاه داده سرور خوانده می‌شود
- محاسبه جمع، تخفیف، هزینه ارسال و مبلغ نهایی
- ثبت سفارش و تولید PDF
- پنل مدیریت برای ثبت/ویرایش محصول و مدیریت وضعیت سفارش‌ها
- ذخیره اطلاعات در SQLite

## استقرار روی Railway
1. این ZIP را از حالت فشرده خارج کنید.
2. محتویات پوشه را در یک مخزن GitHub بارگذاری کنید.
3. در Railway یک پروژه جدید بسازید و گزینه Deploy from GitHub Repo را انتخاب کنید.
4. یک Volume به سرویس وصل کنید و مسیر Mount آن را دقیقاً `/data` بگذارید.
5. در بخش Variables این متغیرها را تنظیم کنید:
   - `KERVA_DB=/data/kerva.db`
   - `KERVA_UPLOAD_DIR=/data/uploads`
   - `KERVA_ADMIN_USER` = نام کاربری مدیر دلخواه
   - `KERVA_ADMIN_PASSWORD` = رمز طولانی و منحصربه‌فرد
   - `KERVA_SECRET` = یک کلید تصادفی طولانی و محرمانه
   - `KERVA_SHIPPING_FEE` = هزینه ارسال (تومان؛ در صورت رایگان بودن 0)
6. Deploy را اجرا کنید. برنامه مسیر `/health` را برای بررسی سلامت دارد.
7. از Settings/Domains در Railway برای ساخت دامنه عمومی استفاده کنید.

**مهم:** بدون Volume پایدار `/data`، دیتابیس و عکس‌های بارگذاری‌شده ممکن است بعد از استقرار مجدد از بین بروند. هیچ قیمت یا محصول نمونه‌ای داخل کاتالوگ قرار داده نشده است.

## عکس محصولات
عکس‌ها باید از بسته‌بندی واقعی و رسمی Kerva باشند. فعلاً هیچ تصویر ساختگی در پروژه قرار نداده‌ایم. پس از ورود به پنل مدیریت، عکس اصلی هر محصول را بارگذاری کنید.

## PDF فارسی
برای نمایش صحیح فارسی، حروف‌چینی و راست‌به‌چپ، بسته‌های `arabic-reshaper` و `python-bidi` در requirements نصب می‌شوند. برای نمایش فونت حرفه‌ای و یکدست، فایل فونت Vazirmatn با مجوز مناسب را در مسیر `fonts/Vazirmatn-Regular.ttf` قرار دهید؛ بدون این فونت، ظاهر PDF ممکن است به فونت جایگزین وابسته باشد.

## نکات پیش از دریافت سفارش واقعی
این نسخه برای راه‌اندازی اولیه است. قبل از استفاده تجاری، CSRF، محدودیت تلاش ورود، سیاست حریم خصوصی، پشتیبان‌گیری منظم و آزمون امنیتی باید تکمیل و بررسی شوند. سفارش‌ها اطلاعات تماس و نشانی مشتری را ذخیره می‌کنند.
